## 已覆盖的关键用户路径

1. 首页读取学科统计并跳转图谱；
2. 旧 hash `/#cnm_221` 跳转数学图谱；
3. 知识图谱按学科、学段、年级、领域、关键词（含旧 external alias）、深度浏览；
4. 知识点详情展示教材、掌握标准、课标、样题；
5. 单点诊断、多目标诊断、演示诊断；
6. 整章诊断和整册/年级筛查；
7. 选择/填空答题、自动判题、手动确认、跳过；
8. 结果页展示掌握、不稳、薄弱、未测、根因、路径，以及题量不足未测先修、范围外先修、无题库先修名称；
9. 结果页可展开已掌握 / 未测清单、关联课标和完整答题记录，并可更正单题结果后重算诊断；
10. 章节筛查实时汇总薄弱 / 不稳，可一键再测本章薄弱或不稳；
11. 可配置单点/整章题量、整体筛查题量和每知识点确认题数；
12. 筛查达到题量上限后可继续加题；
13. 已出题 ID 写入旧版 `cnmDiagnose.seen.v1`，后续诊断默认避开；
14. Canvas 分享海报；
15. v2 格式 JSON 导出和打印（打印时自动展开折叠区）；
16. 孩子档案新增、编辑、删除、备份导入；
17. 孩子历史筛选、最新薄弱 / 不稳汇总、记录展开、再测和删除单条记录；
18. 本机盲区账本和一键再测；
19. PWA 离线刷新和“添加到桌面”提示；
20. 桌面端与移动端无横向溢出；
21. 8 个学科独立图谱包加载，诊断时才加载题库包。
