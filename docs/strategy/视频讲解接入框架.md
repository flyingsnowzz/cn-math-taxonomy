# 视频讲解接入框架（给后续 AI Agent / 内容团队）

> M2 的 AI 讲解与扩题不在本轮开发范围。本轮只落地**视频讲解的接入框架**：
> 页面已经预留统一入口，后续只需要填数据，不需要改任何页面代码。

## 1. 现在产品里已经有的行为

- 知识点答错进入 help 面板时，解析下方出现「看视频讲解」按钮（概念讲解/例题精讲 + 时长）。
- 练习页知识点标题下、补救计划任务卡上有紧凑的「▶ 视频讲解」入口。
- **没有视频的知识点完全不显示入口**，学生无感知。
- 点击在新标签打开外链，记录 `video_open` 埋点（topic、kind），进入本机漏斗数据（M3 上报）。

## 2. 数据结构（唯一需要填的东西）

文件：`web/src/data/topicVideos.ts`

```ts
interface TopicVideo {
  topicId: string          // 知识点 id，如 cnm_148
  kind: 'concept' | 'walkthrough' // 概念讲解 / 典型题精讲
  title: string
  url: string              // 外链（B 站、自建点播等）
  provider?: string
  durationSec?: number
}
// 注册结构：Record<topicId, TopicVideo[]>，同一知识点可挂多个，concept 排在前面
```

两种填法（后续可二选一或并行）：

1. **正式映射**：把内容填入 `PUBLISHED_VIDEOS`（或由构建脚本把 JSON 生成到这里），随版本发布。
2. **本机预览/灰度**：localStorage 键 `cnmVideo.custom.v1`，结构 `{ v:1, videos: Record<topicId, TopicVideo[]> }`。
   内容团队和 AI Agent 产出视频后，先用它在真实页面预览，验证后再进正式映射。`saveCustomVideos(map)` 是现成的写入函数。

数据校验：字段不完整、`topicId` 与挂载位置不一致的条目会被静默丢弃，不影响页面。

## 3. 给 AI Agent 的协作约定

后续配合其他 Agent 做内容时，推荐流水线：

1. 从 `data/topics.json` 取知识点（优先看补救闭环里高频出现的 weak 根因，以及埋点中 `help_view`/`video_open` 多的点）。
2. Agent 产出：视频标题、外链、时长、kind；每个知识点先 1 个 concept 视频，错题精讲按需补 walkthrough。
3. 以 TopicVideo JSON 交付（不要改 Vue 文件）；人工审核标题与链接有效性后合入 `PUBLISHED_VIDEOS`。
4. 验收：挂上后 help 面板出现入口（e2e 模式见 `web/e2e/remedy-video.spec.ts`），点击打开正确地址，埋点有 `video_open`。

## 4. 后续扩展点（当前没做，结构已预留）

- 站内播放器：TopicVideo 增加播放方式字段后，入口组件换成弹层播放即可，页面无需动。
- AI 文字讲解：同一入口区域未来与「看视频」并列「AI 讲解」，help 状态机已支持挂起等待。
- 看完反馈：入口组件可加「看完了/没看懂」按钮回写任务卡，与 M2 讲解效果评估对接。
