# 后续发展方向、价值路径与商业模式

> 结论先行：知识图谱的可视化没有价值，也没有护城河；真正的资产是「**新课标新教材对齐的先修结构 + 节点级题库 + 根因诊断引擎**」。
> 后续一切动作的判断标准：**从「给人看图谱」转向「用图谱替人做决定」—— 出什么题、补什么、怎么排课、AI 怎么讲。**

---

## 一、现状盘点：资产与缺口（截至 2026-11）

### 1. 已有资产

| 资产 | 规模 | 为什么值钱 |
|---|---|---|
| 知识点 | 2997 个（数 870 / 英 791 / 语 493 / 物 269 / 科 222 / 道法 159 / 史 134 / 地 59） | 对齐《2022 课标 2025 修订》、人教新版教材，含掌握标准（mastery_criteria） |
| 先修边 | 4456 条，分 hard/soft，带 reason | 「为什么是前置」可解释，是自适应学习的核心生产资料 |
| 题库 | 12135 题，basic/standard/challenge 分层，带答案与逐题解析 | 已经过两轮审校，可直接用于测评与 AI 讲解 |
| 诊断引擎 | 纯函数、可序列化会话、确认式掌握判定、筛查模式、章节归因、学习路径 | 无依赖、可嵌入任何端（App / 小程 序 / 硬件 / 服务端） |
| 标准映射 | standards / mappings 数据 | 进校、教辅出版所需的合规卖点 |
| 站点 | Vue3 静态站 + PWA，math.pansgo.com | 可信度样板和获客入口 |

### 2. 关键缺口（按致命程度排）

1. **没有学习闭环**：诊断出「配方法薄弱，根因在完全平方公式」之后就结束了——没有针对练习、没有讲解、没有复测。用户带着焦虑来，带着焦虑走。这是当前产品最大的洞。
2. **没有账号与云端数据**：错题本/盲区只是本机 MVP，无法跨设备、无法出家长报告、无法积累「诊断结果 → 教学效果」数据。
3. **数据没有产品化出口**：JSON 在仓库里，没有版本化 API / SDK / 数据规格书 / SLA，B 端没法采购。
4. **节点深度浅**：每个知识点只有题，没有错因标签、变式题组、讲解脚本/微课、认知负荷元数据。对 B 端这意味着「半成品」。
5. **CC BY-NC 许可证**：禁止商用，必须先解决授权模式，否则任何收益路径都走不通（自己是著作权人，可以双许可）。
6. **可视化还在持续吃工程量**（Vue3 迁移刚完成），而它对留存和收入的边际贡献已接近零。

## 二、核心判断：价值在哪里产生

```
现在：  教材 → 图谱（人看）                       价值止于「查阅」
目标：  教材 → 图谱 → 引擎 → 决策（题/课/路径）   价值产生于「替人做决定」
                              ↓
                    给学生：练什么、补什么
                    给老师：布置什么、班里谁需要帮
                    给 AI ：先讲什么、按什么顺序讲
                    给硬件：孩子卡在哪、下一步干什么
```

- **图谱是数据库，不是产品。** 没有人会为「看图谱」付钱，但所有自适应产品都需要这张表。
- **诊断是钩子，不是付费点。** 付费发生在诊断之后：提分练习、家长报告、组卷、API 调用。
- **时间窗口：2025 秋–2026 新教材改版正在逐册落地**（仓库已跟到三上/三下/五上等）。全行业的旧图谱、旧题库正在集体失效，「新教材对齐」是稀缺的、有保质期的稀缺品。

## 三、三个可选方向

### 方向 A：2C —— AI 自适应提分闭环（学生/家长付费）

把站点从「诊断演示」升级为：**诊断 → 个性化练习 → AI 讲解 → 间隔复习 → 周/月家长报告**。

- 产品形态：网页 / 微信小程序；AI 1 对 1 讲题（大模型 + 图谱约束讲解顺序，这是与通用 AI 家教的差异点：先补前置，再讲本题）。
- 付费点：会员订阅、家长报告解锁、错题本云同步、暑期/期末诊断营。
- 优点：产品即 B 端演示样板；能积累效果数据。
- 难点与现实：**双减合规**（义务教育阶段学科类培训受限，工具型/自学型产品可行但营销受限）；C 端获客成本高，留存难做；需要后端、账号、内容持续投入。
- 定位建议：**不作为近期收入主力，作为验证闭环的样板和私域流量入口。**

### 方向 B：2B —— 数据与诊断能力授权（推荐主攻）

客户不是家长，而是「产品里需要这张表」的公司：

| 客户 | 他们的痛点 | 卖什么 | 计费 |
|---|---|---|---|
| AI 学习机/教育硬件（学习机、词典笔、台灯、早教机） | 新教材改版，旧图谱失效；AI 讲题没有先修顺序 | 图谱+题库数据包、诊断 SDK/API | 按设备/按年授权 |
| AI 家教 / 教育大模型 Agent 公司 | 通用 LLM 不会按认知顺序教 | 先修路径 API、出题 API、根因归因 API | 按调用量 / 订阅 |
| 出版社、教辅公司 | 新教材配套诊断卷、分层作业 | 章节诊断模板、题库授权、组卷服务 | 按项目 / 版税 |
| 教育 SaaS / 在线小班课 | 自适应作业、入学测归因 | 引擎嵌入 + 数据授权 | 按校 / 按账号 |

- 为什么最现实：**当前团队最小、资产最匹配、成交周期以周计、不需要流量。**
- 护城河：新教材对齐的持续更新（订阅制的天然理由）+ hard/soft 可解释先修边 + 逐题审校。
- 前提：数据包产品化（版本、diff、schema 文档、质量报告）和商业许可。

### 方向 C：2G/进校 —— 精准教学（长线，客单价高）

- 形态：教师免费工具（组卷、单元测后一键归因、作业分层）→ 学校/区域看板采购（班级薄弱点热力图、区域学情）。
- 付费方：学校信息化经费、区域因材施教项目。
- 优点：客单价高、续约稳、课标映射数据直接成为卖点。
- 难点：销售周期 6–18 个月、需要渠道和关系、产品要配合等保/私有化部署。
- 定位：**B 跑通后的第二阶段，用标杆客户和效果数据再进。**

### 方向排序建议

> **B 为主（现金流）→ A 做样板（兼获客与验证）→ C 为长线（品牌与大单）。**
> 不要再扩学科广度；把深度和商业化出口做出来。

## 四、数据资产需要补的深度

B 端买的是「拿到就能用」。按优先级：

1. **错因标签体系**：每道题标注典型错误类型（计算失误 / 概念混淆 / 前置缺失 / 审题），让诊断结果能直接对应补救动作。
2. **节点级补救包**：每个薄弱知识点配 3–5 道变式题 + 讲解要点（可 AI 生成、沿用现有两轮审校流水线）。
3. **出题能力 API 化**：诊断引擎 + 题库暴露为 HTTP 接口（建图、开会话、判题、取路径、取变式）。
4. **数据版本与更新日志**：教材每册改版产出一个 semver 版本 + diff，订阅客户按年更新。
5. **质量报告产品化**：覆盖率（知识点有题率、先修闭环检查）、审校状态自动出报告——这本身就是销售材料。

## 五、分阶段路线图

### 阶段 0：止血与确权（2–4 周）
- 冻结可视化投入，explore 只维护不迭代。
- 许可证决策：仓库保留 CC BY-NC 开源版，新增商业授权条款（双许可），README 写明商业合作入口。
- 输出《数据规格书 v1》：schema、版本策略、覆盖率、对齐证据。
- 把现有两轮审校流水线脚本化，形成「新教材一册 → 数据更新」的可重复产能。

### 阶段 1：闭环样板 + B 端 MVP（1–3 个月）
- 最小闭环（网页即可）：诊断 → 自动生成针对性练习（复用题库）→ 复测 → 一份可分享的家长报告（PDF/图片）。报告带品牌和获客入口。
- 云端只做最小账号（微信登录 + 报告存档），先不做重后台。
- 诊断引擎包成独立 npm 包 + HTTP API 演示（带 key 的公开 demo）。
- 列出 20 家目标硬件/AI 教育公司，带数据包样本主动 BD，目标：3 家付费 POC。

### 阶段 2：验证付费（3–6 个月）
- B 端：签下首个商业授权（哪怕小），跑通交付、定价、更新机制；定价锚点：数据年授权 + 设备/调用量。
- C 端：用「期末免费诊断 → 报告引流 → 低价会员」验证转化与续费率。
- 按首个客户需求补错因标签和补救包，不为假想需求提前建设。

### 阶段 3：放大（6–12 个月）
- 有 B 端标杆与 C 端效果数据后，进校做 1–2 个标杆校/区。
- 新教材改版跟随到哪里，营销就打到哪里（「2026 春新版已对齐」是持续一年的话题资产）。

### 决策门
- 3 个月内 B 端 0 付费意向 → 说明数据深度不足或找错客户，回头补节点补救包再试；
- C 端报告分享率低/转化极低 → 不重投 App，把 C 端定位收缩为纯获客内容（见下）。

### 轻量备选：内容化变现（投入最小）
即使不做产品，也可以：诊断卷/挂图/手册与出版社合作出版；公众号/视频号「一道题测出知识漏洞」系列引流私域。这条路收入有限，但可与阶段 1 并行，成本低。

## 六、风险与合规

1. **双减**：定位为「自学工具 / 数据服务 / 教师工具」，不做义务教育阶段的排课培训、不在节假日做学科营销；B 端授权不触碰培训资质问题。
2. **教材版权**：对齐目录是事实信息，不受版权保护；题目为 AI 生成自有的题库。商业交付物中不复制教材课文、例题原文、配图。人教社教材名只做兼容性描述。
3. **许可证**：现状 CC BY-NC 禁止他人商用，但自己作为著作权人可另行商业授权。尽早在仓库写清双许可，避免外部贡献者权属不清（如接受外部 PR 需要 CLA）。
4. **数据准确性风险**：AI 初稿 + 审校模式必须保留质量报告和「官方已核/待核」标记，B 端合同里按版本交付，错误有勘误渠道。
5. **窗口期风险**：新教材对齐的稀缺性会随时间衰减（预计 1–2 年），2026–2027 是最好卖的窗口，之后护城河要转向更新速度和节点深度。
