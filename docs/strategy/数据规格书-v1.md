# 数据规格书 v1（Data Specification）

> 面向商业授权与 API/数据包交付。仓库路径约定、字段语义、版本与兼容策略以此文为准。
> 数据现状见 [覆盖率与质量报告](覆盖率与质量报告.md)（由 `scripts/quality_report.py` 自动生成）。

| 文件 | 内容 | 规模（2026-11） |

## 2. 知识点 `topics.json`

数组，元素字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 全局稳定 ID，前缀标识学科（见 §5），一经发布不复用、不改义 |
| `name` | 是 | 知识点名称（教材/课标用语） |
| `subject` | 数学省略 | `english`/`chinese`/`physics`/`science`/`morality`/`history`/`geography`；缺省即数学 |
| `domain` | 是 | 学习领域，如数学「数与代数/图形与几何/统计与概率/综合与实践」 |
| `grade` | 是 | 学段编号（见各学科册次映射，数学 1–22 册） |
| `semester` | 是 | `上`/`下`（高中为`上`） |
| `chapter` | 是 | 册章定位字符串，如「九上 第二十五章 一元二次方程 25.2」 |
| `type` | 是 | `conceptual` / `procedural` / `application` / `reasoning` / `modeling` |
| `description` | 是 | 一句话内容界定 |
| `mastery_criteria` | 是 | 字符串数组，可判定的掌握标准（出题与讲解的依据） |
| `diagnostic_question` | 是 | 兜底诊断题 `{question, answer}`，题库缺失时使用 |
| `standards` | 是 | 课标码数组 `{id, confidence}`，`confidence` 为 `exact`/`inferred` |
| `external` | 是 | 是否外部引入（当前均为 false） |
| `mathLinks` | 物理等跨学科使用 | 用到的数学知识点 ID 数组，**不是**先修边 |
| `root_reason` | 根节点 | 无前驱节点说明其为何是起点 |

## 3. 先修边 `dependencies.json`

数组元素：

| 字段 | 说明 |
|---|---|
| `topicId` | 后继知识点（学这个） |
| `prerequisiteId` | 先修知识点（要先会） |
| `strength` | `hard`：不会先修就无法学后继；`soft`：有帮助但非严格前置。诊断回溯时 hard 优先 |
| `reason` | 人话解释，用于结果页与 API 响应的可解释性 |

约束：无悬空边、无重复边、全局为 DAG（学科内部连通；数学/英语/物理互不连先修边）。

## 4. 题目 `questions.json`

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | `{topicId}_q{n}` |
| `topicId` | 是 | 挂载知识点 |
| `difficulty` | 是 | `basic` / `standard` / `challenge` / `advanced` |
| `type` | 是 | `choice`（选择，含 `choices`）/ `numeric`（数值）/ `short`（简答）/ `self`（自评/开放） |
| `prompt` | 是 | 题干 |
| `answer` | 是 | 参考答案 |
| `explanation` | 是 | 逐题解析 |
| `verify` | 95% 覆盖 | 机器判分表达式/规则（如 `3+1`），支持自动判定 |
| `choices` | 选择题 | 选项数组 |
| `unordered`/`accept`/`hideChoiceText`/`percent` | 可选 | 判分修饰（答案无序、等价接受、百分比等） |
| `figure` | 243 题 | 内联 SVG 示意图引用 |

## 5. ID 与册次约定

ID 前缀：`cnm` 数学、`cne` 英语、`cnc` 语文、`cnp` 物理、`cns` 科学、`cnd` 道法、`cnh` 历史、`cng` 地理；`cnm_p###` 为小学、`cnm_###` 为中学与高中。

数学 grade→册（以数据为准）：grade 1–6 各带上/下为小学一至六年级（共 12 册）；grade 7 上/下、8 上/下、9 上/下为初中七至九年级；grade 10–14（semester 均为`上`）为人教 A 版（2019）必修一、必修二、选择性必修一、二、三。质量报告按 `(grade, semester)` 输出每册点数。教材版本对齐情况见根 README 的分册表与「官方已核/待核」标记。

## 6. 诊断引擎接口（`diagnose/engine.js`）

零依赖 UMD，核心纯函数：

- `buildGraph(topics, deps, questions?)` → 不可变图结构
- `createSession(graph, targetIds, opts)` → 可 JSON 序列化的会话（自适应诊断 / `mode:'screen'` 筛查）
- `nextItem(graph, session)` → `{topicId, question, attempt}`
- `applyAnswer(graph, session, topicId, verdict, meta)` → 新会话（不改入参）
- `summarize(graph, session)` → 根因、掌握/不稳/薄弱分层、按先修排序的学习路径
- `gradeTargets(graph, 册次, subject?)` → 整册诊断范围
- `judgeQuestion(question, text)` → `correct`/`wrong`/`manual`

判定规则：连续答对满额（默认 3）判掌握并推断祖先掌握；答错用更基础题确认，确认也错判薄弱并沿 hard→soft 先修边回溯。

## 7. 版本与兼容策略

- 数据包用语义化版本 `MAJOR.MINOR.PATCH`（见仓库 `VERSION`）：
  - PATCH：题目/解析订正，结构不变；
  - MINOR：新增节点/边/题目、新增册次或学科，ID 只增不改；
  - MAJOR：字段重命名、ID 改义、结构不兼容（交付前提供迁移说明）。
- 每次教材改版对齐产出一个版本，附 CHANGELOG diff（新增/移除/改名节点清单，仓库 `CHANGELOG.md` 已按此维护）。
- 商业授权按版本交付，勘误走 PATCH，订阅期内免费取得更新。

## 8. 已知边界（交付时如实声明）

- AI 生成初稿 + 两轮人工/脚本审校；课标映射含 `inferred` 置信度，教材目录含「待核」标记，以根 README 分册表为准。
- 英语不出听力/口语题；部分新教材册次尚未出版，暂按现行版 densify（README 有清单）。
- 不含教材课文、例题原文与配图；题目均为自有生成内容。
