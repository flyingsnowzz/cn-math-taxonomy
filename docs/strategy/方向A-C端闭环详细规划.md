# 方向 A 详细规划：2C AI 自适应提分闭环

> 前提约束（2026-11）：本阶段不具备 2B/2G 的销售、交付与资质条件，全部资源投入 2C 产品。
> 本文回答四件事：**卖给谁、产品长什么样、分几步做、怎么赚到钱。**

---

## 一、方向 A 到底是什么

一句话：**把现在"诊断完就结束"的演示站，做成"测得出漏洞 → 自动给练习 → 错了能讲懂 → 复测确认补上 → 给家长看到结果"的自学提分工具。**

现在用户的旅程断在第 1 步：

```
诊断（有）→ 学习路径（有，只展示）→ ✗ 练习  → ✗ 讲解  → ✗ 复测  → ✗ 家长报告
```

目标旅程：

```
诊断 → 根因与路径 → 针对性练习（每步 3–5 题）→ 错题 AI 讲解 → 间隔复习
                  → 复测原薄弱点 → 通过 → 生成提分报告（可分享/引流）
```

图谱和引擎从"展品"变成产品的内脏，用户感知到的是"这个工具真的让我孩子把这个分补上了"。

### 与市面通用 AI 家教（夸克、作业帮、豆包）的差异点

它们解决"这道题怎么做"，我们解决"**这类题为什么总错、该从哪个前置点补起、补没补上**"：

1. 先修 DAG 约束讲解与出题顺序（先补前置，再回到目标），通用大模型没有这张表；
2. 2025–2026 新教材对齐，旧产品的知识体系正在失效；
3. 95% 题目机器判分，闭环不需要人工；
4. 结果可解释、可出报告（家长看得懂、愿意转发）。

## 二、目标用户与切入学段（重要的合规取舍）

| 用户 | 角色 | 诉求 |
|---|---|---|
| 初高中学生 | 使用者 | 知道自己卡在哪、题怎么做、考试提分 |
| 家长 | **付费者** | 不辅导作业也能知道薄弱点和进步证据 |
| 小学家长 | 重度使用者/传播者 | 带娃查漏补缺、晒报告 |

**学段切入顺序：高中数学先行，初中数学跟进，小学做引流。** 原因：

1. **双减**管的是义务教育阶段（小学+初中）的学科类"培训"。自学工具可以做，但不能排课、不能老师直播辅导、节假日不能做学科营销；**高中阶段不在双减学科培训限制内，付费意愿（高考）最强、合规风险最低**。
2. 高中数据已齐（必修一/二 + 选必一/二/三，271 个知识点、函数与导数链路完整），是现成的首发范围。
3. 小学内容用于免费引流和口碑（家长转发意愿最强），但不作为首期收费主战场。

定位口径统一为：**「新教材自适应自学工具」**，不是培训、不是辅导班、没有老师排课。

## 三、产品形态选择

| 形态 | 判断 |
|---|---|
| 现有 PWA/网页（Vue3） | **主阵地，立即做**。免审核、迭代快、可被搜索引擎收录、支付用扫码即可 |
| 微信小程序 | K12 学科类目受类目资质限制（培训类目要办学许可），**暂不主攻**；先用公众号/H5 承接微信流量 |
| App | 成本高、留存好，等网页验证闭环与付费后再做（或直接出鸿蒙/安卓学习机合作，那是后话） |
| 公众号/视频号 | 获客与节点营销（月考、期末、新教材）阵地，内容是"一道题测出漏洞"式诊断引流 |

结论：**PWA 网页 + 公众号导流 + 分享报告图片带二维码**，零/轻后端起步。

## 四、核心闭环设计（产品主体）

### 4.1 诊断（已有，做小改）

- 保留现有整册/章节筛查与单目标诊断。
- 结束后不再只展示路径，直接进入「补救计划」：每个薄弱点生成一张任务卡。

### 4.2 补救任务卡（新增，闭环中枢）

每个 weak/shaky 点一张卡：

- 知识点名 + 为什么要学（dep 的 reason，已有）；
- 3–5 道针对性练习（从题库取该点 basic→standard，自动排除本次诊断已做过的题）；
- 全对 → 进入复测；有错 → 触发讲解 + 再给变式；
- 卡片状态：待补 / 学习中 / 待复测 / 已掌握。按学习路径顺序解锁（hard 先修通过后才解锁后继）。

### 4.3 AI 讲解（新增，差异化核心）

讲解不是开放问答，而是**被图谱约束的生成**：

- 输入：知识点的 `description`、`mastery_criteria`、做错的题与解析、直接先修节点；
- 行为：先确认先修（"如果完全平方公式不熟，先看这里"），再按掌握标准讲 1 个例题，出 1 道跟练；
- 边界：只讲当前点与直接先修，不替学生写作业答案，末尾必给跟练题。
- 高中先行；可先用一个大模型 API 接通，提示词模板与节点数据全部自有，模型可替换。

### 4.4 复测与间隔复习（新增，提分证据）

- 复测：对原薄弱点出另一份题（题库中未使用过的 standard/challenge），通过才标"已补上"。
- 复习：对已掌握点按间隔（1/3/7/15 天）推 1–2 题（轻量 SM-2 即可），这是留存抓手。
- 站点本地已有 `blindspots`（盲区汇总）和 `children`（孩子档案/历史）模块，任务卡与复习直接建立在它们之上。

### 4.5 家长报告（新增，付费与传播双驱动）

每次"诊断→复测"完成后生成一页报告（先网页，后导出图片/PDF）：

- 测了什么、发现几个根因、已补上几个、还剩什么；
- 学习路径缩略图 + 本次用时/题量；
- **进步证据**：原薄弱点复测通过（这是家长付费的核心理由）；
- 底部品牌与二维码（免费报告带水印/引流，会员解锁详细版与历史对比）。

### 4.6 关键约束：题量

现有每知识点仅 4–5 题。诊断够用，支撑"练习+变式+复测+复习"不够。需要：

- 用仓库已有的两轮审校流水线（`data/_second_pass`、`scripts/*_bank*`）扩题，目标**高频薄弱点先扩到每点 10–12 题**（basic/standard 为主）；
- 优先级由真实诊断数据决定：上线后先看哪些 weak 根因出现最多，按 Top 50 扩，不全量铺；
- AI 生成 → verify 表达式自判 → 抽检，沿用现有质量门。

## 五、商业模式（C 端）

### 5.1 免费与付费边界

| 功能 | 免费用户 | 会员 |
|---|---|---|
| 诊断 + 根因路径 | ✅ 完整保留（获客入口，不阉割） | ✅ |
| 针对性练习 | 每天/每次限量（如首个薄弱点完整） | 不限 |
| AI 讲解 | 每个薄弱点试听 1 次 | 不限 |
| 复测与间隔复习 | 复测 ✅；复习提醒限量 | 完整 |
| 家长报告 | 带品牌水印的当前报告 | 详细版、历史进步曲线、无水印 |
| 多孩子档案 | 1 个 | 多个 |

原则：**诊断全免费做钩子，"补上来的证据"和持续练习收费。**

### 5.2 定价（验证起点，之后按转化调）

- 月卡 29–39 元、季卡 79–99 元、学期卡（约 5 个月）129–169 元；
- 先不做年卡，等学期续费数据；
- 高中可设更高档（高考意愿强），小学低价引流档。
- 支付：网页扫码支付（微信/支付宝），不依赖小程序资质。

### 5.3 收入公式与目标

> 收入 ≈ 诊断完成人数 × 报告分享率系数（带来新用户）× 会员转化率 × 客单价 × 复购

第一阶段（3 个月）合理目标不是收入规模，而是验证：

- 闭环完成率（诊断→复测通过）≥ 25%；
- 报告分享率 ≥ 10%；
- 付费转化率 1–3%；
- 用 100–300 个真实付费用户验证定价与续费，再谈增长。

## 六、技术方案（最小后端原则）

### 阶段一：纯前端 + 本地存储（0 后端）

- 任务卡、练习进度、错题、复测状态全部进 IndexedDB/localStorage（现有 `storage.ts`、`blindspots.ts` 扩展）。
- 报告分享：生成图片卡片（现有 `shareCard.ts` 基础）+ 可复制链接（现有 `diagnose/share.js` 已有会话分享机制）。
- 优点：一周内可上线闭环；缺点：换设备丢失、无法支付与会员校验。

### 阶段二：最小后端（账号/云存/支付）

- 登录：手机号验证码或微信扫码（网页），只存必要信息；多孩子档案云同步。
- 服务端职责极简：账号、会话与报告云存档、会员状态与支付回调、AI 讲解的模型密钥中转与内容安全。
- 诊断引擎仍在客户端运行（纯函数），服务端不重复实现；题目数据随包下发，高频更新走数据版本接口。
- AI 讲解：服务端代理大模型（密钥不出端、可加内容安全过滤），提示词由知识点 + 先修 + 掌握标准拼装。
- 托管选熟悉的方案即可（静态站 + Serverless/云函数 + 一个文档数据库），不做重运维。

### 数据与质量

- 题库扩题沿用流水线，每批自动跑 `scripts/quality_report.py`，保证有题率/无悬空边不退化；
- 数据包继续按 `VERSION` 语义化发版，前端按版本拉取增量；
- 埋点先记漏斗六步（诊断开始/完成、练习开始/完成、讲解使用、复测通过、报告分享、付费）。

## 九、风险与应对

1. **双减/小程序资质**：高中先行、定位自学工具；不排课、无教师辅导、义务教育阶段不做节假日学科营销；主阵地放网页/PWA。
2. **题量不足**：这是闭环质量的真正瓶颈，M0 上线后立刻按真实薄弱点 Top 50 扩题，不提前全量投入。
3. **工具低频**：用间隔复习、考试节点（月考/期末）推送、家长报告触达；不追求日活，追求"考试前想得起"。
4. **免费大厂替代**：不拼"答疑速度"，拼根因路径、新教材对齐、家长可见的提分证据和干净体验。
5. **AI 讲错**：讲解必须基于自有 mastery_criteria 与解析生成、末尾跟练验证；保留"判定纠错"入口（现有引擎已支持改判重算）；内容安全过滤在服务端。
6. **数据在端上丢失（阶段一）**：明确提示"本地记录"，并尽快用一次报告分享换取注册，缩短无后端窗口期。

## 十、成功长什么样

3 个月后：一个高中生在期末前用 20 分钟测出"函数概念"漏洞根因在初中二次函数，按任务卡练了三天、复测通过，家长收到带进步曲线的报告并转发到家长群；新用户从报告链接进来完成第一次诊断。**这时候图谱才真正变成了生意。**
